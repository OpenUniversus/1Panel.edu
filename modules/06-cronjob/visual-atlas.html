052 个必抄的设计

⭐⭐⭐⭐ 必抄

1. 用户友好 cron 抽象

4 层 + 下拉框，不暴露 5 段表达式。

必抄：Sirius Cloud L3 调度不能让用户写 cron 表达式。简单下拉框，复杂场景才暴露表达式。
⭐⭐⭐⭐ 必抄

2. 下次执行时间预计算

前端展示"还有 X 小时"，UX 提升 10 倍。

实现：用 croniter 库，schedule.Next(from) 算下次时间。

063 个反模式（必避）

⚠️ 状态丢

执行历史在内存里

调度器在 agent 进程内，重启就丢历史。

避坑：把执行历史写 DB（cronjob_history 表），agent 重启也能查。
⚠️ 多机重复

单 agent 进程调度

多机部署每台都跑自己的 cron，同一任务执行 N 次。

避坑：方案 A leader 选举 / 方案 B node_selector / 方案 C etcd/Redis 分布式锁。
❌ 单文件大

cronjob.go 783 行

CRUD + 调度 + 状态机全堆一起。

避坑：拆成 cronjob_crud.go + cronjob_schedule.go + cronjob_history.go 3 个文件。
