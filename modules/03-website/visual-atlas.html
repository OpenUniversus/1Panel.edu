1. 一句话作用 核心

1Panel Website = 自带门卫 + 装修队的网店托管系统: 给一个域名, 它帮你"开"出可访问的网站 (静态/动态/PHP/反代/数据库), 自动写好 OpenResty (Nginx) 配置、自动申请 Let's Encrypt 证书、自动做 HTTPS 跳转、限流、防盗链、跨目录, 还能在 1Panel 面板里让你像用 cPanel 一样点点鼠标维护。

生活类比映射

🏪 实体店

= 创建网站, 一次性配齐所有"开业资料"

🪪 营业执照

= 主域名 (PrimaryDomain)

📑 多块招牌

= WebsiteDomain 表多条记录

🚪 门口保安

= Nginx 反代 / WAF / 防 CC

📦 商品类型

= Website.Type (Static / Runtime / Deployment / Stream / Subsite)

🕐 营业时间

= Status + ExpireDate

📜 工商执照

= WebsiteSSL (HTTPS 证书)

🔁 排班表

= Nginx upstream + LB 算法

📚 后厨账本

= website.DbID / DbType (MySQL/PG)

🔧 装修队

= task.Task 子任务编排

📋 物业报修

= AccessLog / ErrorLog 开关

👥 业主群通知

= x-panel-log 审计日志
