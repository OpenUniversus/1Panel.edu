2HTTP-01 Challenge 验证流程

HTTP-01 原理：CA 服务器主动 GET 域名的 acme-challenge 文件，你的 OpenResty 必须返回 keyAuthorization。

flowchart TD Start([用户申请 HTTP-01 证书]) --> Req[lego 向 CA new-order] Req --> Auth[CA 返回 authorizations] Auth --> Chal[CA 返回 http-01 challenge token] Chal --> Write[lego 写 acme-challenge 文件] Write --> Notify[通知 CA 已就绪] Notify --> Probe{CA 主动 HTTP GET} Probe -->|80 端口可达| Ok[OpenResty 返回 keyAuthorization] Probe -->|不可达| Fail1[CA 标记 invalid] Ok --> Valid[CA 标记 valid] Fail1 --> Retry([重试 5 次]) Valid --> Final[进入 finalize CSR 签发] Retry --> End1([签发失败]) Final --> End2([签发成功])

3DNS-01 Challenge 验证流程

DNS-01 原理：通过 DNS 厂商 API 添加 TXT 记录，CA 服务器查询 TXT 验证。支持通配符。
