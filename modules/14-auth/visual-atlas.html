关键代码片段

// core/app/auth/auth.go:206-219
func CheckPassword(priKey, password, passwordFromDB string) error {
    loginPassword, err := DecryptLoginPassword(priKey, password)
    if err != nil {
        return err
    }
    existPassword, err := encrypt.StringDecrypt(passwordFromDB)
    if err != nil {
        return err
    }
    if !hmac.Equal([]byte(loginPassword), []byte(existPassword)) {
        return buserr.New("ErrAuth")
    }
    return nil
}

6API 接口密钥 (1Panel-Token) 签名

1Panel-Token 是 master 端给外部系统调用的 API 凭据。双算法支持 (MD5 / HMAC-SHA256) + 时间戳防重放 + IP 白名单。关键守卫: 用 API token 调用时,不能再生成新 token (防止递归)。

签名算法对比

V1 (默认)

MD5 算法

简单哈希,兼容性最好。所有语言都能算。

token = md5("1panel" + apiKey + timestamp)
// 例: md5("1panel" + "abc123..." + "1692931200")
HMAC-SHA256

更安全

带密钥的 HMAC,防止 length-extension 攻击。

token = hmac_sha256(apiKey, "1panel:" + timestamp)
// key = apiKey, message = "1panel:1692931200"

校验 5 步 (auth/api_auth.go:34-81)

1. 跳过条件: URL 以 /api/v2/core/auth 开头 → c.Next() 2. 没带 1Panel-Token + 1Panel-Timestamp header → c.Next() (普通登录用户) 3. 读 settings: ApiInterfaceStatus / ApiKey / IpWhiteList / ApiTrustedProxies / ApiKeyValidityTime 4. ApiInterfaceStatus != Enable → 401 ErrApiConfigStatusInvalid 5. isValid1PanelTimestamp(ts, ttl) → 401 ErrApiConfigKeyTimeInvalid 6. isValid1PanelToken(token, ts, key) → 401 ErrApiConfigKeyInvalid 7. isIPInWhiteList(clientIP, whiteList) → 401 ErrApiConfigIPInvalid 8. c.Set("API_AUTH", true) → 放行

8失败限流 (IPTracker)

每个 IP 独立计数,内存常驻最多 100 个 IP,LRU 淘汰。10 次失败锁 5 分钟,失败后强制图形验证码。

常量 (ip_tracker.go:8-13): MaxIPCount = 100 // 内存中最多 100 个 IP 记录 ExpireDuration = 30 * time.Minute // 30 分钟无活动过期 MaxFailedAttempts = 10 // 10 次失败锁 IP LockDuration = 5 * time.Minute // 锁 5 分钟 数据结构: type IPRecord struct { NeedCaptcha bool // 是否需要图形验证码 FailedCount int // 累计失败次数 LockedUntil time.Time // 锁到期时间 LastUpdate time.Time // 最后活动时间 } type IPTracker struct { records map[string]*IPRecord // IP → 记录 ipOrder []string // LRU 队列 mu sync.RWMutex }
