053 个必抄的设计

⭐⭐⭐⭐⭐ 必抄

1. 应用元数据 + 参数化模板

远程 JSON 元数据 + 客户端渲染。

价值：新加应用只改 JSON 不改代码。Sirius Cloud 做应用市场必备。
⭐⭐⭐⭐ 必抄

2. 升级保留用户配置

volume 不删 + env merge。

关键：用户的 /var/www/html 数据保留，只换镜像。WordPress 升级后内容不丢。
⭐⭐⭐⭐ 必抄

3. 定时同步 + ignore 机制

app_sync_task.go 每天拉新版本 + 用户可勾选"忽略更新"。

避坑：ignore 用单独表 + 软删，不用删主表记录。

063 个反模式（必避）

❌ 拼写错误

app_ingore_upgrade.go

少了 n（应该是 ignore）。1Panel 自己也留着了没改。

避坑：抄的时候改名。代码 review 要把拼写检查当 lint rule。
⚠️ 强依赖外部

1Panel-dev/appstore 仓库挂了就装不了

整套应用商店逻辑假设 appstore 在线。

避坑：本地缓存 appstore JSON（app_sync_task.go 做的）+ 多镜像源 fallback。
❌ 大杂烩

app_utils.go 2119 行

任何 install/upgrade 都要调它。

避坑：拆成 app_meta.go / app_deps.go / app_render.go / app_helpers.go 4 个文件。

必抄清单

  1. 应用元数据 + 参数化模板（远程 JSON 模式）
  2. 升级保留用户配置（volume 不删 + env merge）

抄的时候要改

  1. 不要拼写错误（别学 ingore）
  2. 元数据放自己 Git 仓库（不依赖 1Panel-dev）
  3. 支持私有应用市场（企业版场景）
