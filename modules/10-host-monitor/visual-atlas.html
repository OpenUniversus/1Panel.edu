052 个必抄的设计

⭐⭐⭐⭐⭐ 必抄

1. 指标采集 + ring buffer

1 分钟采样，60 个点环形缓冲。

必抄：Sirius Cloud L1 readyz 需要"机器健康状态"，L3 Obs 需要"历史指标图"。Python psutil + deque 30 行能写完。
⭐⭐⭐⭐ 必抄

2. 远程命令 4 重防御

RBAC + 黑名单 + 超时 + 审计日志。

必抄：你 L2 资产管理如果给用户"跑命令"功能，4 重防御必须都做。少任何一重都可能造成安全事故。

063 个反模式（必避）

🔴 高危

远程命令 = 巨大安全风险

Core 被入侵 → 攻击者能跑任意命令 = 整台机器沦陷。

避坑：默认禁用远程命令。必须 RBAC + MFA + 黑名单/白名单 + 全部命令审计告警。
⚠️ 频率不够

采样间隔 1 分钟（不是 15s）

满足不了高频监控（瞬时 spike 抓不到）。

避坑：Sirius Cloud L3 Obs 用 Prometheus 体系（15s 采样）。1Panel 这套只适合基础监控。
❌ 单点过大

device_clean.go 1118 行

大文件扫描策略复杂（白名单 + 用户确认 + 多种来源）。

避坑：先实现"找 top 100 大文件" + "用户手动删"，不要做自动删。
