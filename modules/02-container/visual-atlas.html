051 个核心抽象 + 1 个借鉴模式

⭐⭐⭐⭐ 核心

Docker SDK 隔离层

用 moby/moby/client Go SDK 直接调 unix socket。

好处：性能更好 + 错误处理结构化 + 类型安全。不要用 exec.Command 调 docker CLI。
⭐⭐⭐⭐ 借鉴

CRUD 抽象模式

所有资源都只要 5 个操作：List / Get / Create / Update / Delete。

Sirius Cloud 借鉴：MySQL 实例 / Redis 实例 / PG 实例都遵循 5 个操作，UI 层不关心底层。

062 个反模式（必避）

❌ 强依赖 Docker

整套模块依赖 /var/run/docker.sock

假设 Docker daemon 存在。

Sirius Cloud：你不用 Docker，整个模块不引入。约束是硬性的，不要想着绕。
❌ 1:1 映射

container.go 1961 行 = Docker API 翻译

几乎所有函数都是调 SDK 一个方法 + 翻译参数。

避坑：不要自己手写"容器 CRUD 抽象层"，让前端直接调 Docker API 或 K8s API。
