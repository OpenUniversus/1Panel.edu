044 个必抄的模式

⭐⭐⭐⭐⭐ 必抄

1. 路由级 RBAC

meta.permission + 全局守卫。

必抄：React Router v6 同款模式。meta.permission 集中管权限，新增页面只加路由 + meta。
⭐⭐⭐⭐⭐ 必抄

2. API 类型从后端 DTO 自动生成

openapi-typescript 一行命令。

必抄：你已经有 FastAPI + Pydantic V2，openapi-typescript http://localhost:8000/openapi.json -o src/api/types.ts 自动生成。
⭐⭐⭐⭐ 必抄

3. xterm.js / monaco-editor / noVNC

3 个强大开源库集成。

必抄：xterm.js = 浏览器 SSH 终端 / monaco-editor = VS Code 同款 / noVNC = 远程桌面。你的 L2 资产管理 + L3 部署都要。
⭐⭐⭐⭐ 必抄

4. Element Plus 扩展机制

自定义指令 + 业务组件封装。

对位：你用 Ant Design 5，可以包一层类似封装：自定义 hooks + 业务 Table/Form/Dialog 组件。

053 个反模式（必避）

❌ GPL + 风格

不要照搬 UI 风格

GPL v3 + 你有自己的设计系统。

避坑：抄模式（目录结构 / 路由权限 / API 抽象），不抄样式。你用 Ant Design 5，风格自动不同。
⚠️ 拆太细

488 view 文件 = 单点过多

hot reload 慢，1Panel 自己也有这问题。

避坑：不要上来就拆 14 业务域。先按"核心 5 个 + 工具箱"拆：database / host / alert / settings / auth + misc。
⚠️ 版本老

Element Plus 2.14 是较老版本

部分组件 API 有变化。

避坑：不要 pin 老版本。跟着 Ant Design 5 升级（你用 Ant Design）。
